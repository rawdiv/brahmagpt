# 🧠 BrahmaGPT

BrahmaGPT is a fully self-contained, full-stack AI chatbot project designed to be trained on **custom datasets**, capable of learning, processing, and responding without relying on external APIs.

> ✨ Inspired by the creator’s vision of **divine-level intelligence**, BrahmaGPT is built for next-gen applications like customer support, smart assistants, knowledge bots, and more.

---

## 🚀 Features

- 🔒 Fully local & API-independent (no OpenAI or external API calls)
- 🧠 Train on your own data (PDFs, docs, websites, etc.)
- 📡 Custom API support for real-time fetching & answering
- 🗣️ Chat UI with smooth conversational flow
- 🌐 Web-based frontend (React.js) with backend (Python/FastAPI or Node.js)
- 📚 Embedding + Vector DB for long-term memory
- 🛠️ Modular architecture (easy to plug in new models or tools)

---

## 🏗️ Tech Stack

| Layer     | Tools/Libraries           |
|-----------|---------------------------|
| Frontend  | React.js, TailwindCSS     |
| Backend   | FastAPI / Node.js (Express) |
| LLM       | Brahma |
| Vector DB | Chroma / FAISS / Weaviate |
| Auth      | Firebase / Supabase (Optional) |
| DB        | PostgreSQL / MongoDB (Optional) |
