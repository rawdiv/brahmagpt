Brahma: Your Own LLM Project

Train, Fine-Tune, and Deploy Custom Large Language Models

Get Started Explore on GitHub

Key Features

Complete Model Architecture

Transformer-based decoder-only architecture with modern techniques like RoPE embeddings and grouped-query attention.

Training Pipeline

Efficient training with mixed precision, gradient accumulation, and learning rate scheduling.

Inference Tools

Text generation and chat interfaces for easy model usage.

Customizable

Configure model size, training parameters, and more via config files.

Web Platform

Full-featured web interface for managing models, datasets, and user accounts.

API Integration

Comprehensive RESTful API for programmatic access.

Project Structure

brahma/ ├── api/ # API server and endpoints ├── config/ # Configuration files ├── data/ # Training data ├── models/ # Model architecture ├── training/ # Training pipeline ├── utils/ # Utility functions ├── inference/ # Inference code ├── train.py # Training script └── README.md # Project documentation

Quick Start Guide

# Clone the repository git clone https://github.com/rawdiv/brahmallm.git # Navigate to the project directory cd brahmallm/brahma # Install required packages pip install -r requirements.txt # Generate sample data (optional) python train.py --create_sample_data --sample_data_size 1000 # Train the model using the default configuration python train.py --config config/default_config.json # Start the web platform python start_brahma.py
