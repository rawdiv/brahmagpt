Brahma Documentation

Brahma is a comprehensive framework for training and using your own large language model (LLM) similar to ChatGPT. This project includes everything you need to train, fine-tune, and deploy your custom LLM.

Features

Complete Model Architecture

  • Transformer-based decoder-only architecture
  • RoPE embeddings
  • Grouped-query attention
  • Modern optimization techniques

Training Pipeline

  • Mixed precision training
  • Gradient accumulation
  • Learning rate scheduling
  • Efficient data loading

Inference Tools

  • Text generation interface
  • Chat completion
  • Batched inference
  • Quantization support

Web Platform

  • User authentication
  • Model management
  • Training monitoring
  • API key management

Installation

Requirements

Install the required packages:

pip install -r requirements.txt

Quick Start

1. Generate Sample Data (Optional)

python train.py --create_sample_data --sample_data_size 1000

2. Train Your Model

python train.py --config config/default_config.json

For distributed training:

python -m torch.distributed.launch --nproc_per_node=N train.py --config config/default_config.json

3. Chat with Your Model

python -m inference.chat --model_path checkpoints/checkpoint-final.pt

Model Architecture

Configuration

Customize the model architecture in config/default_config.json:

{ "model_config": { "vocab_size": 32000, "hidden_size": 4096, "intermediate_size": 11008, "num_hidden_layers": 32, "num_attention_heads": 32, "num_key_value_heads": 8, "max_position_embeddings": 4096 } }

Training Pipeline

Training Configuration

Adjust training parameters in config/default_config.json:

{ "training_config": { "learning_rate": 1e-4, "weight_decay": 0.01, "warmup_steps": 500, "max_steps": 100000, "gradient_accumulation_steps": 1, "mixed_precision": true, "batch_size": 8 } }

Custom Training

Preparing Your Data

Prepare your data in jsonl format:

{"text": "Your training example here"}

Update the data configuration:

{ "data_config": { "dataset_path": "path/to/your/data", "train_split": "train", "validation_split": "validation", "text_column": "text" } }

Fine-tuning

Fine-tuning Process

To fine-tune an existing checkpoint:

python train.py --config config/finetune_config.json --resume_from_checkpoint path/to/checkpoint.pt

Deployment

Exporting Models

Export your model to ONNX format:

python -m conversion.export_onnx --model_path checkpoints/checkpoint-final.pt --output_path model.onnx

API Reference

Python Client

import brahma # Initialize the API client client = brahma.Client(api_key="your-api-key") # Make a chat completion request response = client.chat.completions.create( model="brahma-7b", messages=[ {"role": "user", "content": "Hello, how are you?"} ] ) print(response.choices[0].message.content)
